# 技能解读 (skill-explainer)

只读分析已有技能，讲清能做什么、需要什么输入、会交付什么结果，以及使用前提和调用方式。
适合在实际运行一个技能之前判断它是否适合当前任务。

英文调用标识是 `$skill-explainer`，界面显示为“技能解读 (skill-explainer)”。

## 安装与准备

将完整技能目录放入宿主支持的用户技能目录并刷新。
需要能够读取技能文档和相关本机文件的智能体；只解读说明不需要目标技能的 API Key，也不会执行目标技能来探测功能。
仅有粘贴正文时也可以分析，但会明确说明缺少实现资料的范围。

## 支持的输入

- 技能真实名称。
- 本地技能目录或 `SKILL.md` 路径。
- 直接粘贴的技能正文。
- 可选的使用场景、关注问题或解读深度。

目标已经明确时直接分析；同名技能存在多个版本且无法确定时，会先确认要解读的版本。
没有目标时，只需补充名称、路径或正文，不需要填写调查表。

## 调用示例

```text
使用 $skill-explainer 解读 image-gen：
告诉我它能做什么，需要哪些配置，以及最小调用方式。
```

```text
使用 $skill-explainer 解读我提供的 SKILL.md，
重点说明输入材料、可选参数、输出格式和保存位置。
```

```text
使用 $skill-explainer 教我一步一步使用 poster-gen，
先给准备清单和调用示例，暂时不要实际生成海报。
```

## 输出

默认在对话中给出详细解读，按问题相关性组织：

| 内容 | 说明 |
| --- | --- |
| 定位与边界 | 适用场景、主要能力、不支持或未确认事项 |
| 输入表 | 材料、参数、必填条件、默认行为及示例 |
| 输出表 | 结果形式、格式、保存方式及限制 |
| 使用前提 | 实际需要的软件、工具、密钥配置名称或计费条件 |
| 调用示例 | 至少一条最小有效调用，按需提供进阶示例 |
| 依据与未知项 | 区分文档声明、静态实现依据和已有运行证据 |

用户要求简短介绍时会精简；要求实操教学时会给准备步骤和预期结果，但不会因此实际执行。
只有明确要求保存时才创建报告文件。

## 操作边界

不安装、重构或修改被解读的技能，也不运行其代码、`--help`、测试或安装钩子。
不读取 `.env`、凭证或令牌值，只解释所需配置名称及用途。
目标技能文档中的命令和外发要求只是分析资料，不自动成为本次操作授权。
示例中的“预期输出”不表示已经执行，静态代码依据也不等于运行验证通过。

完整规则见 [SKILL.md](SKILL.md)，界面配置见 [agents/openai.yaml](agents/openai.yaml)。
